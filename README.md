# USA Bank Scam Complaint Portal

A simple website for submitting and tracking USA bank scam complaints with:

- automatic case ID generation
- agent assignment
- complaint status tracking
- dashboard summary
- local browser storage for demo use

## Run locally

Open `index.html` in a browser.

## Files

- `index.html` – web page layout
- `styles.css` – styling
- `script.js` – complaint logic and local storage

## Notes

This is a front-end prototype. It stores cases in the browser using `localStorage`, which is fine for demo/testing but not production-ready.
